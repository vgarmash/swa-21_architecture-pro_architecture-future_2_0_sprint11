# Расширенный технический радар «Будущее 2.0»

## Введение

Данный технический радар отражает стратегический выбор технологий и архитектурных паттернов для трансформации IT-ландшафта компании «Будущее 2.0». Все технологии отобраны с учётом ограничений санкционного режима и требований к импортозамещению.

## Методология оценки

| Статус | Описание | Критерии |
|--------|----------|----------|
| **Adopt** | Рекомендуется к использованию | Стабильная технология, соответствует стратегии, поддержка дружественных стран |
| **Trial** | Пилотное внедрение | Перспективная технология, требует验证ции в условиях компании |
| **Assess** | На исследовании | Технология требует дополнительного анализа или находится в стадии зрелости |
| **Hold** | Не рекомендуется | Технология устарела, не соответствует требованиям или недоступна |

## Рекомендации по применению

### Горизонт 0-6 месяцев (Пилот)

1. **Adopt**: Apache Kafka, PostgreSQL/Postgres Pro, Kubernetes, Terraform
2. **Trial**: Apache Flink, MLflow, Prometheus + Grafana
3. **Assess**: ClickHouse, NiFi

### Горизонт 6-18 месяцев (Масштабирование)

1. **Adopt**: Trino, Apache Superset, DataHub, Open Policy Agent
2. **Trial**: Yandex Cloud ML, Amundsen
3. **Assess**: YDB, Data Vault 2.0

### Горизонт 18-36 месяцев (Целевое состояние)

1. **Adopt**: Полный Data Mesh, Event-Driven Architecture
2. **Trial**: Data Fabric (если докажет эффективность)
3. **Hold**: Legacy-системы выведены из эксплуатации

---

## Примечание по санкциям

Все рекомендации составлены с учётом следующих ограничений:

- Запрещены облачные сервисы AWS, Azure, GCP
- Ограничены западные базы данных (Oracle, IBM)
- Ограничены BI-инструменты (Tableau, Power BI)
- Рекомендуются российские и дружественные решения
- Open-source технологии используются без ограничений
