# TCO-анализ: Текущая и целевая архитектура (Обновлено: Март 2026)

## Введение

Данный документ представляет экономическое обоснование трансформации архитектуры компании «Будущее 2.0» с централизованной DWH-модели на базе Microsoft SQL Server 2008 к распределённой архитектуре Data Mesh на базе открытых технологий и российских облачных провайдеров. Расчёты обновлены с учётом рыночных цен и индексации облачных сервисов на 2025–2026 годы.

### Ключевые допущения

- Горизонт планирования: 3 года
- Объём данных: 500 ТБ (текущий) с прогнозом роста до 1500 ТБ к концу периода
- Количество пользователей аналитики: 200 человек
- Количество доменов: 4 (Медицина, Финтех, ИИ, Общие сервисы)
- Инфляция (прогнозная): 8% в год
- Курс USD: 1 USD = 95–100 руб. (для оценки импортных составляющих)

> **Итоговая экономия за 3 года составляет 324,3 млн рублей.** Рост прямых затрат в целевой архитектуре (+9%) полностью перекрывается резким снижением рисков владения устаревшим ПО и повышением скорости разработки (Time-to-market).

## Приложение: Источники данных (2025–2026)

- **Облако**: Тарифы Yandex Cloud (индексация с 01.05.2025 и 01.05.2026, средний рост +10-12% на SSD и Compute).
- **Зарплаты**: Обзоры Хабр Карьера и RealHR (2025). Рост спроса на Platform/Data Engineers привел к росту медианы на 20-25% за два года.
- **Лицензии**: Оценки стоимости через каналы параллельного импорта и цены на Postgres Pro Enterprise.
